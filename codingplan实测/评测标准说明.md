## 测试任务

为保证评测公平性，所有平台均使用相同的测试任务进行评估。

### 当前测试任务：Word 智能水印溯源系统

测试任务为开发一款"**Word 智能数字水印与溯源系统**"工具，具备以下核心功能：

**核心功能需求**：
- **水印嵌入**：为 Word 文档嵌入唯一、隐蔽、可抗破坏的溯源水印（UID）
- **分析溯源**：从疑似泄露文档中提取并解密水印，还原原始接收者信息
- **密钥管理**：支持多项目密钥的创建、导入、导出、删除

**技术要求**：
- PySide6 GUI 界面，支持文件拖拽
- python-docx + lxml 处理 DOCX 文件
- cryptography 库实现 AES-256 加密
- SQLite 数据库存储密钥和分发记录
- 五层冗余备份策略（防 WPS/Word 重写）

**项目规模**：约 1100 行代码，包含：
- 核心水印模块（嵌入/提取算法）
- 数据库模型（密钥/记录管理）
- UI 主窗口（双标签页）
- 安装脚本与依赖管理

## 质量评级标准

### ⭐⭐⭐⭐⭐ 评级标准（客观判定）

**⭐⭐⭐⭐⭐ = 直接可运行 + 功能完整 + 结果正确**

评级必须同时满足以下全部条件：

| 条件 | 说明 |
|------|------|
| **直接可运行** | 代码无语法错误、无导入错误，无需任何修改即可执行 |
| **核心功能完整** | 水印嵌入 + 水印提取 两个核心功能均已实现 |
| **结果正确** | 人工验证：嵌入后能成功提取出水印信息 |

### 降级规则

| 评级 | 标准 | 说明 |
|------|------|------|
| ⭐⭐⭐⭐⭐ | 直接可运行 + 核心功能完整 + 结果正确 | 最佳状态，直接可用 |
| ⭐⭐⭐⭐ | 直接可运行 + 核心功能完整，但结果验证失败 | 功能实现但输出错误 |
| ⭐⭐⭐ | 可运行，有明显功能缺陷或缺失一个核心功能 | 部分可用 |
| ⭐⭐ | 仅框架可用，核心功能不完整或运行报错 | 框架级实现 |
| ⭐ | 仅有注释、伪代码或完全不可运行 | 最低级别 |

### 核心功能定义

每轮评测前需明确两个核心功能：

1. **水印嵌入** — 将溯源信息写入 Word 文档
2. **水印提取** — 从文档中还原溯源信息

辅助功能（密钥管理、CLI、GUI 等）不计入核心功能判定。

### 验证方式

- **可运行性**：执行 `python main.py`，观察是否有语法/导入错误
- **功能完整性**：检查代码是否包含嵌入和提取的核心逻辑
- **结果正确性**：人工操作验证 — 嵌入 → 提取 → 确认数据一致

## 综合评分权重

综合评级由 **质量得分**、**Token 效率得分** 和 **RPM 效率得分** 三部分组成。

### 质量得分（50% 权重）

| 质量等级 | 得分 | 说明 |
|----------|------|------|
| ⭐⭐⭐⭐⭐ | 100 分 | 直接可运行 + 核心功能完整 + 结果正确 |
| ⭐⭐⭐⭐ | 80 分 | 直接可运行 + 核心功能完整，但结果验证失败 |
| ⭐⭐⭐ | 60 分 | 可运行，有明显功能缺陷或缺失一个核心功能 |
| ⭐⭐ | 40 分 | 仅框架可用，核心功能不完整或运行报错 |
| ⭐ | 20 分 | 仅有注释、伪代码或完全不可运行 |

### Token 效率得分（30% 权重）

Token 效率得分基于 Token 消耗计算，以最低 Token 消耗为基准（100 分）：

```
Token 效率得分 = (最低 Token 消耗 / 实际 Token 消耗) × 100
```

| 效率等级 | 得分范围 | 说明 |
|----------|----------|------|
| ⭐⭐⭐⭐⭐ | 90-100 分 | Token 效率最优 |
| ⭐⭐⭐⭐ | 70-89 分 | Token 效率良好 |
| ⭐⭐⭐ | 50-69 分 | Token 效率一般 |
| ⭐⭐ | 30-49 分 | Token 效率较低 |
| ⭐ | <30 分 | Token 效率差 |

### RPM 效率得分（20% 权重）

RPM（Requests Per Minute）效率得分基于每分钟请求数限制计算，RPM 越高表示平台并发能力越强：

```
RPM 效率得分 = (实际 RPM / 最高 RPM) × 100
```

对于"无限制"平台，RPM 效率得分按 100 分计算。

| RPM 等级 | 得分范围 | 说明 |
|----------|----------|------|
| ⭐⭐⭐⭐⭐ | 90-100 分 | 无限制或高并发 |
| ⭐⭐⭐⭐ | 70-89 分 | 并发能力良好 |
| ⭐⭐⭐ | 50-69 分 | 并发能力一般 |
| ⭐⭐ | 30-49 分 | 并发能力较低 |
| ⭐ | <30 分 | 并发能力差 |

### 综合评级计算

```
综合得分 = 质量得分 × 50% + Token 效率得分 × 30% + RPM 效率得分 × 20%
```

| 综合评级 | 得分范围 |
|----------|----------|
| ⭐⭐⭐⭐⭐ | 90-100 分 |
| ⭐⭐⭐⭐ | 70-89 分 |
| ⭐⭐⭐ | 50-69 分 |
| ⭐⭐ | 30-49 分 |
| ⭐ | <30 分 |
