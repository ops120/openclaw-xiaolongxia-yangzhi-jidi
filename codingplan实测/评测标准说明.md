> **声明**: 以下所有数据均为实测数据，评测时间：2026年4月

## 测试任务

为保证评测公平性，所有平台均使用相同的测试任务进行评估。

### 当前测试任务：Word智能水印溯源系统

测试任务为开发一款"**Word智能数字水印与溯源系统**"工具，具备以下核心功能：

**核心功能需求**：
- **水印嵌入**：为Word文档嵌入唯一、隐蔽、可抗破坏的溯源水印（UID）
- **分析溯源**：从疑似泄露文档中提取并解密水印，还原原始接收者信息
- **密钥管理**：支持多项目密钥的创建、导入、导出、删除

**技术要求**：
- PySide6 GUI界面，支持文件拖拽
- python-docx + lxml 处理DOCX文件
- cryptography 库实现AES-256加密
- SQLite 数据库存储密钥和分发记录
- 五层冗余备份策略（防WPS/Word重写）

**项目规模**：约1100行代码，包含：
- 核心水印模块（嵌入/提取算法）
- 数据库模型（密钥/记录管理）
- UI主窗口（双标签页）
- 安装脚本与依赖管理

## 评测标准

采用 GitHub 标准格式记录评测数据，字段说明如下：

| 字段 | 说明 |
|------|------|
| **codingplan平台** | 评测的 AI 编程平台名称 |
| **模型** | 使用的 AI 模型版本 |
| **代码工具** | 代码生成/辅助工具名称 |
| **任务数** | 完成的测试任务数量 |
| **Token** | 消耗的 Token 总量（输入+输出） |
| **请求** | API 调用总次数 |
| **时长/s** | 完成任务的总耗时（秒） |
| **首交完成度** | 首次响应的代码完整度评级 |

### 评测数据记录格式

```csv
codingplan平台,模型,代码工具,任务数,Token,请求,时长/s,首交完成度
```

### 首交完成度评级标准

| 评级 | 标准 | 说明 |
|------|------|------|
| ⭐⭐⭐⭐⭐ | 90-100% | 直接可运行，功能完整 |
| ⭐⭐⭐⭐ | 70-89% | 可运行，存在小问题需微调 |
| ⭐⭐⭐ | 50-69% | 部分可运行，需要较多修改 |
| ⭐⭐ | 30-49% | 仅框架可用，核心功能缺失 |
| ⭐ | <30% | 仅有注释或伪代码 |
