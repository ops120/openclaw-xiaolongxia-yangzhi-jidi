# 语音转文字（STT/ASR）产品深度调研报告 (2026年4月更新)

## 1. 中国市场主流产品深度解析

### **通义听悟 (阿里巴巴)**
*   **发布时间**：2023年6月正式发布，持续迭代。
*   **试用步骤**：
    1. 访问 [tingwu.aliyun.com](https://tingwu.aliyun.com) 或下载通义听悟App。
    2. 登录阿里云账号。
    3. 新用户开通服务可获得 **90天免费试用期**。
*   **免费额度**：
    *   实时记录：每天 48 小时。
    *   音视频文件转写：每天 2 小时。
*   **付费标准 (新版接口)**：
    *   **ASR转写**：0.6 元/小时。
    *   **大模型总结**：0.064 元/小时/项（如摘要、待办、关键词各计费一次）。
    *   **翻译**：实时翻译 4 元/小时；离线翻译 0.5 元/小时。
*   **核心特点**：视频PPT提取、大模型自动总结、多端同步。

### **飞书妙记 (字节跳动)**
*   **发布时间**：2020年随飞书4.0版本推出，2026年春季发布会进一步强化AI协作能力。
*   **试用步骤**：
    1. 注册并登录 [飞书](https://www.feishu.cn)。
    2. 在侧边栏或会议中开启“妙记”。
    3. 基础版用户完成认证后可获得 **100 GB 存储空间**。
*   **付费标准**：
    *   **基础版**：免费使用，受限于存储空间（认证后100GB）。
    *   **商业标准版**：50 元/人/月，提升存储和协作权限。
    *   **商业专业版**：80 元/人/月，面向成长型团队。
*   **核心特点**：深度集成办公套件，智能纪要自动生成，支持100+语种翻译。

### **讯飞听见 (科大讯飞)**
*   **发布时间**：2015年上线，2026年2月发布星火X2大模型增强版。
*   **试用步骤**：
    1. 访问 [iflyrec.com](https://www.iflyrec.com) 或下载讯飞听见App。
    2. 注册登录，新用户通常有少量免费时长赠送。
*   **付费标准**：
    *   **机器快转**：约 0.33 元/分钟（时长卡模式，如50小时畅享包约368元/年）。
    *   **人工精转**：中文 2.17 元/分钟起；英文 30 元/分钟起。
    *   **会员权益**：月卡/年卡提供每月固定转写时长（如4小时/月）。
*   **核心特点**：专业领域（医疗、法律）识别精度极高，支持方言，硬件联动。

### **腾讯会议 (腾讯)**
*   **付费标准**：
    *   **个人版**：免费使用基础转写（限时体验）。
    *   **专业版**：98 元/月 或 988 元/年。提供不限时长实时转写、会议字幕。
    *   **商业版**：115.84 元/月/账号（按年），提供400GB云录制空间。

## 3. 开源项目与新兴 AI 产品

*   **Whisper (OpenAI)**: 2022年9月发布，目前最强开源模型。
*   **FunASR (阿里达摩院)**: 2023年开源，针对中文优化，支持 Paraformer 模型。
*   **Faster-Whisper**: 社区优化版，推理速度提升显著。
*   **试用方式**: 通常通过 GitHub 克隆仓库，使用 Python 环境部署（如 `pip install faster-whisper`）。
