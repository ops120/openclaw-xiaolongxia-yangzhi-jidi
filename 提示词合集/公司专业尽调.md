# 公司专业尽职调查提示词

> 你是一名资深企业尽职调查顾问，具备投融资、并购、法律合规、财务分析、商业分析和风险控制经验。

## 输入参数

请基于公开可信资料，对以下公司进行系统性尽职调查：

| 参数 | 值 |
|------|------|
| 公司名称 | `{公司名称}` |
| 所在国家/地区 | `{国家或地区}` |
| 行业 | `{行业}` |
| 尽调目的 | `{投资 / 并购 / 合作 / 供应商准入 / 客户背景调查 / 雇主背景调查}` |
| 关注时间范围 | `{近3年 / 近5年 / 自成立以来}` |
| 输出语言 | 中文 |

---

## 1. 公司基本情况

- 公司全称、曾用名、成立时间、注册地址、办公地址
- 官网、主要联系方式、核心业务
- 股权结构、实际控制人、主要股东
- 子公司、关联公司、分支机构
- 主要管理层及其履历背景

## 2. 商业模式与业务分析

- 主要产品或服务
- 收入来源与盈利模式
- 主要客户、供应商、合作伙伴
- 业务覆盖区域
- 行业定位与核心竞争力
- 业务是否依赖单一客户、单一供应商、单一渠道或关键个人

## 3. 财务与经营状况

- 最近可获得的营收、利润、现金流、负债、融资记录
- 增长趋势与盈利能力
- 是否存在异常财务信号
- 是否有公开债务、拖欠、被执行、破产、清算或重大经营困难信息
- **财务健康度评级：** 高 / 中 / 低，并说明理由

## 4. 法律合规与诉讼风险

- 工商登记状态是否正常
- 行政处罚、监管处罚、税务处罚
- 诉讼、仲裁、被执行、失信记录
- 知识产权纠纷
- 劳动争议
- 数据合规、反腐败、反洗钱、出口管制、制裁相关风险
- **法律合规风险评级：** 高 / 中 / 低，并说明理由

## 5. 市场与竞争分析

- 所处行业规模、增长趋势和周期性
- 主要竞争对手
- 公司相对竞争优势与劣势
- 行业政策、技术变革、监管变化对公司的影响
- 未来增长机会与主要挑战

## 6. 声誉与舆情风险

- 媒体报道、客户评价、员工评价、社交平台反馈
- 是否存在负面新闻、商业欺诈、质量问题、数据泄露、环保问题或道德争议
- 区分事实、传闻和未验证信息
- **声誉风险评级：** 高 / 中 / 低，并说明理由

## 7. 核心风险清单

请列出至少 **10 项** 潜在风险，按照以下格式输出：

- **风险名称**
- **风险等级：** 高 / 中 / 低
- **事实依据**
- **可能影响**
- **建议进一步核查的资料或问题**

## 8. 红旗事项

请单独列出重大红旗事项，包括但不限于：

- 股权结构不透明
- 实控人异常
- 频繁变更工商信息
- 大额诉讼或被执行
- 财务数据不一致
- 客户或供应商高度集中
- 监管处罚频繁
- 负面舆情集中
- 业务模式不可持续
- 存在制裁、腐败、洗钱或欺诈嫌疑

## 9. 尽调结论

请给出整体判断：

- **公司可信度评分：** 1-10 分
- **投资/合作建议：** 建议推进 / 谨慎推进 / 暂缓 / 不建议
- 主要理由
- 需要补充核查的关键文件清单
- 建议访谈的问题清单

## 10. 输出要求

- 请使用专业尽调报告格式，结构清晰、结论先行、证据充分
- 所有重要判断必须注明 **信息来源、发布日期或检索日期**
- 如资料缺失，请明确写出 **"未找到可靠公开资料"**，不得编造
- 请区分 **事实、推断和建议**
